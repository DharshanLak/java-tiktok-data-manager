# TikTok Data Manager

A Java application for managing TikTok user statistics such as
followers and likes.

## Features

- Load TikTok user data from a text file
- Search for user information
- Add and update entries
- Remove entries
- Save modified data
- Console and graphical user interfaces
- JUnit unit testing
- Exception handling

## Technologies

- Java
- ArrayList
- Object-Oriented Programming
- File I/O
- JUnit 5
- Maven
- Visual Studio Code

## Testing

JUnit tests are included to verify data retrieval, removal,
nonexistent-entry handling, and loading stored TikTok data.
